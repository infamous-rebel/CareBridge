The package is a flat leaf module exposing three concerns through `__init__.py` re-exports: (1) `schemas.py` — Pydantic v2 `BaseModel` definitions for domain entities such as Medication, Appointment, FamilyMember, RefillOrder, DeliveryOrder, AuditEvent, CareEvent, ResolutionResult, StatusSummary, PendingAction, and FamilyPreferences; forward references are resolved via `StatusSummary.model_rebuild()` at import time. (2) `audit_log.py` — append-only SQLite persistence of `AuditEvent`s with schema bootstrapped in `init_audit_db`, enforced immutability via BEFORE UPDATE/DELETE triggers that raise ABORT, and query helpers (`write_audit_event`, `get_audit_events`) parameterized by an optional `db_path` defaulting to `audit.db`. (3) `escalation_logic.py` — pure Python function `classify_action` that maps an action type plus optional context into one of `auto` / `alert` / `approve` using hardcoded sets (`AUTONOMOUS_ACTIONS`, `REQUIRES_ALERT`, `REQUIRES_APPROVAL`, `EMERGENCY_TRIGGERS`); unknown actions safely default to `approve`. Dependency direction is one-way: consumers import from `src.models`; this module has no imports from application code.
